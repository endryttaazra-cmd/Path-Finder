# PATH-FINDER 🧭
**Web-Based Archaeological Navigation System for Temple Sites in Semarang City**

PATH-FINDER adalah platform navigasi dan visualisasi interaktif untuk menjelajahi Objek Diduga Cagar Budaya (ODCB) peninggalan peradaban Hindu-Buddha abad ke-8 hingga ke-15 Masehi di Kota Semarang.

## 🌟 Fitur Utama
- **Digital Visualization of ODCB**: Peta spasial interaktif lokasi candi dan peninggalan sejarah di Semarang.
- **Trans Semarang BRT Routing**: Integrasi rute transportasi publik lokal untuk memudahkan aksesibilitas lokasi.
- **Instant Ride-Hailing Integration**: Akses cepat pemesanan transportasi online (Grab/Gojek).
- **Interactive Site Catalog**: Informasi detail dan kaji sejarah dari tiap objek situs.

## 🛠️ Struktur Project
- `frontend/`: Tampilan antarmuka pengguna berbasis web interaktif.
- `backend/`: Server, pengolahan data spasial, dan API.
